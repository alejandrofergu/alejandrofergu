# Alex Fernandez

I do security and software work from Geelong, Australia. Contract development, plus incident response.

Most of my work is in private client repos, so this profile is quieter than the work is.

### Recent

I investigated and remediated a supply chain compromise at a software company with 20-plus staff. A fraudulent remote contractor, consistent with the DPRK IT worker scheme, had injected loader code into internal repos. I scoped the affected repos and files, removed the code, coordinated endpoint cleanup, and traced falsely attributed commits back to an offboarded account whose access was never revoked. The trace came down to commit author metadata, which GitHub renders as identity but does not verify.

Earlier I was a computer technician. I did device remediation for people hit by social engineering scams, and ran Microsoft 365 and Azure AD administration for small business clients.
